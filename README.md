## 关于 Git 与网盘的区别

Git 记录的是文件的每一次变化——谁在什么时候改了什么、为什么改，
可以随时回到任意一个历史版本。网盘只保存文件最后的样子，
想看改了什么只能靠人比。Git 是"时间机器"，网盘是"储物柜"。
